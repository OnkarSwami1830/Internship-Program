# Sales & Customer Analysis Dashboard

## Overview
This project is a beginner-friendly sales and customer analysis portfolio project built using realistic Indian sales data. It demonstrates practical uses of Excel, SQL, and Power BI for business analysis.

## Objective
To analyze sales performance, customer behavior, product contribution, payment preferences, and monthly trends in a clear and industry-relevant way.

## Tools Used
- Microsoft Excel
- MySQL / SQL
- Power BI
- Python for dataset generation

## Dataset
File: `Dataset/sales_data.csv`

The dataset includes realistic sales records from Indian cities such as Pune, Mumbai, Delhi, Bangalore, Hyderabad, Chennai, Jaipur, Ahmedabad, Nagpur, Nashik, and Kolkata.

## Data Cleaning
The project includes a step-by-step cleaning process covering missing values, duplicates, invalid dates, invalid discounts, negative sales, negative quantities, and region mismatches.

## Excel Analysis
File: `Excel/Sales_Analysis.xlsx`

The workbook includes:
- Raw_Data
- Cleaned_Data
- Calculations
- Pivot_Analysis
- Dashboard

## SQL Analysis
File: `SQL/sales_analysis.sql`

The SQL script includes database creation, table definitions, insert statements, and analysis queries.

## Power BI Dashboard
Guide: `PowerBI/Dashboard_Guide.md`

The dashboard includes KPI cards and visuals for monthly sales, region sales, category analysis, top products, city performance, payment mode, and customer sales.

## How to Run
1. Open the CSV file to inspect the dataset.
2. Open the Excel workbook to review formulas and pivot analysis.
3. Run `sales_analysis.sql` in MySQL Workbench.
4. Import the dataset into Power BI and follow `Dashboard_Guide.md`.
